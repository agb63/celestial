# Celestial

Celeste clone. Project to learn PyGame and code with the kids.

## Goals

- Create an open-ended project that the kids and I can jam on for a long time
- Teach the kids about source control
- Use the github issues system to plan and track work
- Learn PyGame
- Practice pixel art, sprite and animation creation, music creation

## Brainstorm Breakdown

Ideas for big pieces we'll need to address:

- Large, scrolling maps connected into levels
- Level nav / lobby area
- NPC conversations
  - dialog trees
  - dialog box UI
  - text effects ("typewriter" reveal, wiggling for emphasis)
  - character portrait art
- Game menus UI & logic
- Scripted in-engine cutscenes
- Scripted live events, e.g., bridge falling out at beginning
- Level-complete / key-moment splash screens
- Madeline
  - momentum / physics
  - collision with world and entities
  - dash tracking and physics
  - control state machine and animations
- Zoom-in effect e.g., while talking to NPCs
- Particle effects
- Save files & restoration
- Interactible entities
  - Bouncy clouds, etc
  - Death spikes, etc
  - Strawberries
  - Crumble platforms
  - Moving / tossing platforms
  - Hearts
  - B-sides
  - "Collect the pieces" strawberry puzzles
